# Mãos que Ajudam

Projeto front-end desenvolvido para uma organização fictícia do terceiro setor.

## Sobre o projeto

A aplicação tem como objetivo apresentar os projetos sociais da ONG Mãos que Ajudam, divulgar suas iniciativas e permitir o cadastro de doadores, voluntários e pessoas que precisam de ajuda.

## Funcionalidades

- Navegação em formato SPA
- Exibição dinâmica de projetos
- Formulário de cadastro
- Validação de campos
- Armazenamento de cadastros no localStorage
- Recuperação do histórico de cadastros
- Formatação de datas com Day.js
- JavaScript modular com ES6 Modules
- Melhorias de acessibilidade
- Navegação por teclado
- Mensagens acessíveis de validação

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- ES6 Modules
- LocalStorage
- Day.js
- Git
- GitHub
